# CTRLCV 剪贴板

轻量的 Windows 剪贴板历史工具，托盘常驻。

## 运行
双击 `start.bat`（无黑窗口），或 `python main.py`。依赖：Python 3.10+、PySide6。

## 用法
- **Alt+V** 在光标处呼出（可在配置里改）
- 输入即搜索，空格分隔多个关键词
- 单击条目在右侧预览完整内容；文本可直接编辑，停止输入后自动保存，之后复制/粘贴用的就是改过的内容（图片、文件只读）
- 在右侧选中一部分文字，按 `Ctrl+C` 或「复制」按钮只复制选中部分
- 没选中文字时，`Ctrl+C` / `Ctrl+Enter` / 「复制」按钮复制整条
- 双击或 `Enter` 粘贴到原窗口 · `Shift+Enter` 纯文本粘贴
- `Ctrl+1~9` 快速粘贴第 N 条 · `Ctrl+P` 置顶 · `Ctrl+D` 删除 · `Esc` 关闭
- 右键有更多操作
- 往命令行窗口（cmd / PowerShell / Windows Terminal / Git Bash）粘贴图片时，会自动把图片存成文件并粘贴路径，方便发给 Claude Code 等命令行工具；其他窗口（如 VS Code 终端）可右键图片 →「粘贴为文件路径」。图片文件默认存在 `%APPDATA%\CTRLCV\images`（可用配置项 `image_dir` 改到别处），7 天后自动清理
- 顶部标题栏可拖动移动窗口，右侧有 📌 固定和 ✕ 隐藏按钮
- 点搜索框右边的 📌 固定在最前：点击别处不再自动隐藏，粘贴/复制后也保留；可拖动窗口空白处移动位置，位置和固定状态都会记住
- 拖动窗口边缘/右下角调整大小，拖动列表与预览之间的分隔条调整左右比例；尺寸自动记住，托盘菜单可「重置窗口尺寸」

## 特性
- 支持文本（保留富文本格式）、图片、文件
- 重复复制自动去重并移到最前；置顶条目不会被清理
- 历史保存在 SQLite，重启不丢；默认保留 500 条
- 自动跳过密码管理器标记为敏感的内容
- 托盘菜单：暂停记录、开机自启、清空历史

## 配置
`%APPDATA%\CTRLCV\config.json`
```json
{ "hotkey": "Alt+V", "max_items": 500, "max_image_mb": 20 }
```
窗口尺寸会自动写入 `window_size`（宽, 高）和 `splitter`（列表宽, 预览宽），也可手动改。
hotkey 示例：`Ctrl+Shift+V`、`Win+Alt+V`、`Ctrl+F12`。修改后从托盘退出再重新启动。
